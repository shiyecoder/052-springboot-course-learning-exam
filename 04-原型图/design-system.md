# 设计系统 · 在线课程学习与考试系统

> 依据需求文档第 10 节「UI 设计规范」落地，色值、框架尺寸与组件规则均以文档为准。
> 主色 `#1B4F72`（教学蓝）承担顶部栏、主按钮、当前菜单与关键数字，不引入大面积渐变与插画。

## 1. 视觉方向

| 维度 | 决策 | 理由 |
|---|---|---|
| 主色 | `#1B4F72` | 教育场景需要稳定、可信的深蓝；同色同时用于后台侧栏与门户顶栏，保证两端是同一个系统 |
| 辅助色 | `#2E86AB` | 次级按钮、筛选选中态、普通图表系列；与主色同色相，层级靠明度区分 |
| 强调色 | `#F39C12` | 待办数量、待批阅、高风险提示；只做小面积点睛，不做大面积底色 |
| 背景 | `#F5F6F7` | 内容区底色，表格与表单统一白色容器，边界靠 1px `#E3E6E8` 分隔 |
| 圆角 | 6px（控件）/ 10px（门户大卡） | 教育系统偏克制，圆角不做胶囊化，避免像消费级 App |
| 阴影 | `0 1px 3px rgba(31,41,51,.06)` | 只用于卡片抬升，列表行不做阴影 |
| 字体 | 系统字族，正文 13px / 行高 1.6 | 表格密集，13px 能在 1440 宽下容纳 9–10 列而不横向滚动 |

## 2. 字体阶梯

| 用途 | 字号 / 字重 | 颜色 |
|---|---|---|
| 页面标题 | 18px / 600 | `#1F2933` |
| 卡片标题 | 13.5px / 600 | `#1F2933` |
| 正文与表格 | 12.5–13px / 400 | `#1F2933` |
| 次要说明 | 11.5–12px / 400 | `#5B6770` |
| 辅助 / 时间戳 | 11px / 400 | `#8A949C` |
| 关键数字（KPI） | 21px / 600 | 主色，`letter-spacing:-.3px` |

## 3. 布局栅格

- 后台：左侧栏固定 220px，顶部栏 56px，内容区外边距 24px，内容区独立滚动（`height:100vh` + `.content overflow:auto`），避免整页被菜单撑高。
- 门户：顶栏 56px，内容最大宽度 1240px 居中，课程卡 4 列（≥1200px）/ 3 列（≥900px）。
- 间距基数 4px：卡片内边距 14px，栅格间距 12px，区块间距 12–14px，表单项纵向 14px。
- 表单标签固定 104px 右对齐，单列输入最大 520px，搜索下拉 180–240px（不夸张也不局促）。

## 4. 状态色语义

| 语义 | 色值 | 使用场景 |
|---|---|---|
| 成功 / 已完成 / 已发布 | `#2B7955` + 浅底 `#E6F2EC` | 已出分、已归档、低风险、完成标记 |
| 进行中 / 正常 | `#2E86AB` | 学习中、进行中、关注 |
| 待处理 / 待批阅 / 中风险 | `#F39C12` + `#FDF3E1` | 待审核、待批阅、待发布 |
| 危险 / 驳回 / 高风险 | `#B02A37` + `#FBEAEC` | 驳回、不及格、高风险、强制交卷 |

状态标签一律「小圆点 + 中文文案」，不依赖颜色单独表达含义（色盲可用性）。

## 5. 角色视觉区分

| 角色 | 框架 | 视觉特征 |
|---|---|---|
| 系统管理员 / 教务管理员 / 任课教师 / 助教 | 后台管理（侧栏 + 顶栏 + 内容区） | 深蓝侧栏、白底密集表格、筛选条常驻表格上方 |
| 学生 | 门户（顶栏导航 + 内容流） | 深蓝顶栏、课程卡片 + 进度条、大留白、强调色用于待办 |

同一系统内两套框架共用同一色板与组件，差异只在导航形态与信息密度，避免学生端看起来像另一个产品。

## 6. 图标

`design/icons.svg` 为 symbol 雪碧图，共 40 个图标，24×24 线性、`stroke-width:1.7`、圆角端点，覆盖导航（看板/课程/章节/题库/阅卷/成绩/预警/统计/讨论/消息/用户/角色/菜单/字典/日志）、操作（搜索/新增/导出/上传/刷新/筛选/编辑/删除/查看/下载）、状态（对勾/时钟/警示/旗帜/锁）。

使用时：`<svg><use href="icons.svg#i-book"/></svg>`；最终 Vue 工程以 `components/Icon.vue` 统一封装同名图标。

## 7. 一屏约束

后台数据看板在 1440×900 下必须一屏（8 个 KPI + 6 个图表，`body.scrollHeight = 900`）：
KPI 卡 68px、图表卡内容 150px、卡片间距 12px、图表标题行 18px。超出时优先压缩图表高度（不低于 120px），不删图表。
